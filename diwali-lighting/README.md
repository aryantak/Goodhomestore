# Diwali Lighting Redesign

Interactive before/after concept for the house facade photo — shifting from a cool blue curtain wash to a warm, layered Diwali look that still respects the modern architecture.

## Open the guide

Open [`index.html`](./index.html) in a browser (or serve the folder):

```bash
python3 -m http.server 8765 --directory diwali-lighting
```

Then visit `http://localhost:8765`.

## What’s inside

- Full-bleed photo hero of the current setup
- Diagnosis of the blue wash vs. the warm accents that already work
- Interactive facade toggle: **Current** vs **Redesign**
- Five-zone install plan (roof → balconies → wall → porch → interior spill)
- Color temperature palette and shopping kit sized to this elevation

## Design intent

| Keep | Change |
|------|--------|
| Dense festive coverage | Cool blue as the main fill |
| Star-burst wall sconces | Flat monochrome glow on white walls |
| Porch / gate warmth | Curtain density that hides architecture |

Target mix: **~70% warm white / amber**, **20% marigold**, **≤10% cool accent**.
